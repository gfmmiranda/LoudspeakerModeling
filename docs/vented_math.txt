VENTED LOUDSPEAKER — MATHEMATICAL FOUNDATION
=============================================

GOAL
----
Model a moving-coil loudspeaker mounted in a vented enclosure using a
lumped-parameter, small-signal, frequency-domain formulation.

The system has three coupled dynamic variables:

    I   = voice-coil current
    Ud  = driver diaphragm velocity
    Uv  = vent air velocity

The model couples:

    electrical domain
        ↓
    driver mechanical domain
        ↓
    enclosure / vent mechanical-acoustic domain


ASSUMPTIONS
-----------
1. Linear small-signal behavior.
2. Harmonic steady state:
       exp(jωt)
3. Driver diaphragm behaves as a rigid piston.
4. Air in the vent behaves as a lumped moving mass.
5. Cabinet air behaves as a lumped compliance / spring.
6. Wavelengths are large relative to relevant enclosure/vent dimensions.
7. Nonlinear effects such as turbulence, suspension nonlinearity,
   BL(x), Le(i), compression, thermal effects, etc. are initially ignored.
8. Radiation and vent losses may initially be approximated using
   lumped resistive terms.


VARIABLES AND PARAMETERS
------------------------

Electrical:

    V       applied voltage [V]
    I       voice-coil current [A]
    Re      DC voice-coil resistance [ohm]
    Le      voice-coil inductance [H]
    Bl      force factor [N/A = V s/m]

Driver mechanical:

    xd      diaphragm displacement [m]
    Ud      diaphragm velocity = d(xd)/dt [m/s]
    Md      effective moving mass [kg]
    Rd      mechanical damping [N s/m]
    Kd      driver suspension stiffness [N/m]

Usually:

    Md = Mms
    Kd = 1 / Cms
    Rd = Rms


Vent:

    xv      vent-air displacement [m]
    Uv      vent-air velocity = d(xv)/dt [m/s]
    Sv      vent cross-sectional area [m²]
    av      vent radius [m]
    T       physical vent length [m]

Cabinet / air:

    Sd      effective diaphragm area [m²]
    V0      net internal enclosure volume [m³]
    rho0    equilibrium air density [kg/m³]
    c       speed of sound [m/s]


============================================================
1. ELECTRICAL EQUATION OF THE DRIVER
============================================================

The blocked electrical impedance of the voice coil is

    Ze = Re + jωLe

Motion of the voice coil generates a back EMF:

    e_back = Bl Ud

Therefore Kirchhoff's voltage law gives:

    V = Ze I + Bl Ud

or

    (Re + jωLe) I + Bl Ud = V


============================================================
2. ELECTROMECHANICAL FORCE
============================================================

Current in the voice coil generates Lorentz force:

    Fe = Bl I

This drives the diaphragm.


============================================================
3. CABINET PRESSURE
============================================================

The diaphragm and vent both change the volume of the enclosed air.

Choose positive coordinates such that:

    diaphragm inward motion compresses the box
    vent outward motion relieves compression

Then the net volume compression is

    ΔV = Sd xd - Sv xv

For small adiabatic compression of air:

    pb = rho0 c² ΔV / V0

Hence:

    pb = (rho0 c² / V0) (Sd xd - Sv xv)

where pb is the acoustic pressure inside the enclosure.


============================================================
4. FORCES GENERATED BY BOX PRESSURE
============================================================

Pressure acting on the driver creates force:

    Fbd = Sd pb

Substituting pb:

    Fbd =
        (rho0 c² Sd² / V0) xd
        -
        (rho0 c² Sd Sv / V0) xv


Pressure acting on the vent air slug creates force:

    Fbv = Sv pb

so

    Fbv =
        (rho0 c² Sd Sv / V0) xd
        -
        (rho0 c² Sv² / V0) xv


Define:

    Kbd = rho0 c² Sd² / V0

    Kbv = rho0 c² Sv² / V0

and the driver-vent coupling stiffness

    mu = rho0 c² Sd Sv / V0


Therefore:

    Fbd = Kbd xd - mu xv

and

    Fbv = mu xd - Kbv xv


============================================================
5. PHYSICAL VENT MASS
============================================================

The air inside the vent has volume

    Vvent = Sv T

and therefore mass

    Mv = rho0 Sv T


============================================================
6. VENT END CORRECTION
============================================================

Air outside the physical vent also participates in the oscillatory motion.

Using the low-frequency radiation-reactance approximation from the
reference model:

    Mv' = Mv + 8 rho0 Sv av / (3π)

Therefore:

    Mv' = rho0 Sv Leff

where

    Leff = T + 8 av / (3π)

and

    8 / (3π) ≈ 0.849

The exact end correction depends on port termination geometry, so this
coefficient can later be generalized.


============================================================
7. VENT / CABINET STIFFNESS
============================================================

The equivalent mechanical stiffness seen by the vent is

    Kbv = rho0 c² Sv² / V0

This follows directly from:

    ΔV = Sv xv

    pb = rho0 c² ΔV / V0

    F = pb Sv

therefore:

    F = (rho0 c² Sv² / V0) xv


============================================================
8. HELMHOLTZ / VENT RESONANCE
============================================================

The vent air mass and cabinet air stiffness form a mass-spring oscillator.

Its angular resonance frequency is:

    ωb = sqrt(Kbv / Mv')

Using

    Kbv = rho0 c² Sv² / V0

and

    Mv' = rho0 Sv Leff

gives:

    ωb = c sqrt(Sv / (V0 Leff))

and therefore

    fb = c / (2π) * sqrt(Sv / (V0 Leff))


This is the standard Helmholtz tuning expression.


============================================================
9. VENT RADIATION RESISTANCE
============================================================

At low frequency, the vent opening radiates acoustic energy into the
surrounding medium.

Using the small-radiator approximation:

    Rrv = rho0 Sv² ω² / (2π c)

This represents real mechanical power lost through acoustic radiation.

A more complete model may also include viscous / turbulence losses:

    Rv_total = Rrv + Rloss

For the first implementation, either:

    Rv_total = Rrv

or a simplified constant damping term may be used.


============================================================
10. VENT MECHANICAL IMPEDANCE
============================================================

Mechanical impedance is defined as:

    Zm = F / U


For a mass:

    ZM = jωM


For viscous resistance:

    ZR = R


For a spring:

    ZK = K / (jω)
       = -j K / ω


Therefore the vent mechanical impedance is

    Zmv =
        Rv_total
        +
        j(ω Mv' - Kbv / ω)


If only radiation resistance is used:

    Zmv =
        Rrv
        +
        j(ω Mv' - Kbv / ω)


At ω = ωb:

    ω Mv' = Kbv / ω

so the reactive terms cancel and:

    Zmv(ωb) = Rv_total


============================================================
11. DRIVER EQUATION OF MOTION — TIME DOMAIN
============================================================

Newton's law for the driver gives:

    Md xddot_d
    + Rd xdot_d
    + Kd xd
    + Fbd
    =
    Bl I

Using:

    Fbd = Kbd xd - mu xv

gives:

    Md xddot_d
    + Rd xdot_d
    + (Kd + Kbd) xd
    - mu xv
    =
    Bl I


Thus:

    Md xddot_d
    + Rd xdot_d
    + (Kd + Kbd) xd
    - mu xv
    =
    Bl I


============================================================
12. VENT EQUATION OF MOTION — TIME DOMAIN
============================================================

The vent has no electrical motor.

Its motion is generated by box pressure.

Newton's law gives:

    Mv' xddot_v
    + Rv_total xdot_v
    =
    Fbv

with

    Fbv = mu xd - Kbv xv

Therefore:

    Mv' xddot_v
    + Rv_total xdot_v
    + Kbv xv
    - mu xd
    =
    0


============================================================
13. HARMONIC / FREQUENCY-DOMAIN CONVERSION
============================================================

Assume:

    x(t) = X exp(jωt)

Then:

    U = dx/dt = jωX

and:

    X = U / (jω)

Also:

    d²x/dt² = -ω² X


============================================================
14. DRIVER MECHANICAL IMPEDANCE
============================================================

Convert the driver equation to velocity form.

Starting from:

    Md xddot_d
    + Rd xdot_d
    + (Kd + Kbd) xd
    - mu xv
    =
    Bl I

Using X = U/(jω):

    [Rd + j(ωMd - (Kd + Kbd)/ω)] Ud
    + j(mu/ω) Uv
    =
    Bl I


Define:

    Zmd =
        Rd
        +
        j(ωMd - (Kd + Kbd)/ω)


Therefore:

    Zmd Ud + j(mu/ω) Uv = Bl I


============================================================
15. VENT MECHANICAL IMPEDANCE EQUATION
============================================================

From:

    Mv' xddot_v
    + Rv_total xdot_v
    + Kbv xv
    - mu xd
    =
    0

we obtain:

    Zmv Uv + j(mu/ω) Ud = 0

where

    Zmv =
        Rv_total
        +
        j(ωMv' - Kbv/ω)


============================================================
16. COMPLETE COUPLED SYSTEM
============================================================

There are three unknowns:

    I
    Ud
    Uv


Electrical equation:

    Ze I + Bl Ud = V


Driver mechanical equation:

    -Bl I
    + Zmd Ud
    + j(mu/ω) Uv
    =
    0


Vent equation:

    j(mu/ω) Ud
    + Zmv Uv
    =
    0


Matrix form:

            | Ze       Bl            0       | | I  |   | V |
            | -Bl      Zmd       j mu/ω      | | Ud | = | 0 |
            | 0        j mu/ω      Zmv       | | Uv |   | 0 |


At each angular frequency ω:

    solve A(ω) y(ω) = b

where:

    y = [I, Ud, Uv]^T


============================================================
17. DRIVER DISPLACEMENT
============================================================

Once Ud is known:

    Xd = Ud / (jω)

Driver excursion magnitude:

    |Xd|

This can be compared directly with Xmax.


============================================================
18. VENT DISPLACEMENT
============================================================

Similarly:

    Xv = Uv / (jω)

The vent-air velocity itself is:

    |Uv|

This quantity is useful for evaluating port turbulence / chuffing.


============================================================
19. VOLUME VELOCITIES
============================================================

Driver volume velocity:

    Qd = Sd Ud


Vent volume velocity:

    Qv = Sv Uv


Be careful with sign convention.

The front radiation of the driver and the external radiation of the vent
must be combined using their complex phases, not by adding magnitudes.


============================================================
20. ACOUSTIC RADIATION
============================================================

For a simple monopole far-field approximation:

    p(r,ω) ≈ j rho0 ω Q / (4πr) * exp(-jkr)

where:

    k = ω / c


Depending on the radiation geometry (2π half-space, baffled piston,
4π free-space, etc.), the coefficient changes.


The total radiated pressure from a vented enclosure is:

    p_total(ω) =
        p_driver(ω)
        +
        p_vent(ω)


Both must be treated as complex quantities.


Never compute:

    |p_driver| + |p_vent|

Instead compute:

    p_total = p_driver + p_vent

then:

    SPL =
        20 log10(
            |p_total| / pref
        )

with:

    pref = 20e-6 Pa


============================================================
21. INPUT IMPEDANCE
============================================================

The electrical input impedance is:

    Zin = V / I


This should display the characteristic two-peak impedance curve of a
vented enclosure.

The frequency between the two impedance maxima is approximately the
cabinet tuning frequency fb.


============================================================
22. RELATION TO ACOUSTIC-DOMAIN FORMULATION
============================================================

Instead of using mechanical vent velocity Uv [m/s], the enclosure can
also be described using acoustic volume velocity Q [m³/s].

The cabinet acoustic compliance is:

    Cab = V0 / (rho0 c²)


Its acoustic impedance is:

    Zab = 1 / (jω Cab)


The vent acoustic mass / inertance is:

    Map = rho0 Leff / Sv


Its acoustic impedance is:

    Zap = jω Map


Mechanical and acoustic quantities are related by area squared.

For the vent:

    Zmv = Sv² Zap


because:

    F = p Sv

    Q = Sv U

therefore:

    F/U
    =
    (p Sv) / (Q/Sv)
    =
    Sv² p/Q


Likewise for the cabinet compliance:

    Kbv = Sv² / Cab


This explains the recurring S² factors in loudspeaker equivalent
circuits.


============================================================
23. IMPORTANT PHYSICAL BEHAVIOR
============================================================

Near fb:

    - vent volume velocity becomes large
    - driver excursion reaches a minimum
    - significant acoustic output comes from the vent
    - cabinet pressure strongly loads the driver


Below fb:

    - port impedance becomes increasingly mass-unloading / low
    - pressure inside the enclosure falls
    - driver becomes weakly mechanically loaded
    - cone excursion rises rapidly
    - acoustic response falls steeply

This is why vented enclosures often require a high-pass filter.


Above fb:

    - vent contribution decreases
    - driver increasingly dominates radiation


============================================================
24. NUMERICAL IMPLEMENTATION
============================================================

For each frequency f:

    ω = 2πf

Compute:

    Ze
    Mv'
    Kbd
    Kbv
    mu
    Rrv
    Zmd
    Zmv

Build:

    A =
        [[Ze,            Bl,             0],
         [-Bl,           Zmd,       j*mu/ω],
         [0,         j*mu/ω,           Zmv]]

and:

    b = [V, 0, 0]

Then solve:

    [I, Ud, Uv] = solve(A, b)


Postprocess:

    Xd = Ud / (jω)
    Xv = Uv / (jω)

    Qd = Sd Ud
    Qv = Sv Uv

    Zin = V/I

Then compute:

    driver excursion
    vent velocity
    electrical impedance
    driver pressure
    port pressure
    total SPL
    phase


============================================================
25. USEFUL VALIDATION TESTS
============================================================

The implementation should reproduce several known limiting cases.

A. Vent blocked:
       Uv -> 0

   The model should approach a sealed enclosure.


B. Very large V0:
       Kbd, Kbv, mu -> 0

   The enclosure loading disappears and the system approaches free-air
   driver behavior.


C. At fb:

       Im(Zmv) ≈ 0

   because:

       ωMv' ≈ Kbv/ω


D. Near fb:

       |Xd| should show a pronounced minimum

       |Uv| should show a maximum


E. Electrical impedance:

   The vented enclosure should show two resonance peaks rather than the
   single resonance peak of a sealed enclosure.


F. Energy / phase:

   Driver and port acoustic pressure must be combined as complex
   quantities.


============================================================
26. POSSIBLE NEXT-LEVEL EXTENSIONS
============================================================

After the basic model works, add progressively:

    - finite voice-coil inductance model beyond constant Le
    - vent viscous losses
    - enclosure leakage losses
    - stuffing / absorption losses
    - port end corrections depending on flange geometry
    - finite-length port resonances
    - piston radiation impedance
    - baffle diffraction
    - driver rear radiation into the cabinet
    - finite box modes
    - nonlinear port flow
    - compression / thermal effects
    - nonlinear suspension Cms(x)
    - nonlinear force factor BL(x)
    - frequency-dependent Le
    - passive radiator model
    - multiple drivers / ports


============================================================
CORE EQUATIONS — MINIMAL SUMMARY
============================================================

Electrical:

    Ze = Re + jωLe

    Ze I + Bl Ud = V


Box:

    Kbd = rho0 c² Sd² / V0

    Kbv = rho0 c² Sv² / V0

    mu  = rho0 c² Sd Sv / V0


Vent:

    Mv = rho0 Sv T

    Mv' = Mv + 8 rho0 Sv av/(3π)

    Rrv = rho0 Sv² ω²/(2πc)


Mechanical impedances:

    Zmd =
        Rd + j(ωMd - (Kd + Kbd)/ω)

    Zmv =
        Rrv + j(ωMv' - Kbv/ω)


Coupled equations:

    Ze I + Bl Ud = V

    -Bl I + Zmd Ud + j(mu/ω) Uv = 0

    j(mu/ω) Ud + Zmv Uv = 0


Helmholtz tuning:

    fb =
        c/(2π)
        sqrt(
            Sv/(V0 Leff)
        )


Outputs:

    Xd = Ud/(jω)

    Qd = Sd Ud

    Qv = Sv Uv

    Zin = V/I
